# 正在播放验证

运行开发服务后，打开 `http://127.0.0.1:1420/tests/fixtures/media-player.html`。
页面上可切换经典、封面卡片、流彩黑胶、极简横条，检查各主题三档布局、长标题、深浅外观、缺少封面/进度/音量和禁用控制。封面卡片的中号为 224 × 356 竖向，其余中号为 364 × 170。封面卡片和黑胶从本地封面取色；封面缺失或读取失败时回退。黑胶仅在播放时转动，减少动态效果时保持静止。偏好设置 → 正在播放 → 播放器主题可选择并保存，切换主题与尺寸时检查原生窗口方向、屏幕边缘与重启后的尺寸。预览里的示例曲目不代表当前播放内容。三款对比预览位于 `tests/fixtures/media-themes.html`。
此页面使用真实 MediaFace 组件和本地生成的静音音频，不访问网络，不包含在生产构建中。
高度对齐预览位于 `tests/fixtures/media-alignment.html`：自动排布竖版播放器与两个小组件，检查顶边、底边一致，间距为 16，全部播放控件完整显示。
主题设置采用四宫格和统一高度的预览区，检查每行卡片、名称及说明对齐；中号竖版按预览区高度等比缩小，横版居中，窄窗口自动改为单列。检查小号封面卡片的播放按钮完全位于封面右下角。极简横条使用不透明黑底，包括无媒体状态；桌面极简主题右上角为真实进程频谱，暂停后清零，切换主题或关闭组件后停止采集。无法确定唯一播放器进程、系统不支持或采集失败时静止，不退回全系统采集。设置预览仍是明确标注的示例动画。真实数值显示测试位于 `tests/fixtures/media-spectrum.html`，检查低频、高频、静音、不可用、旧来源、暂停和三种尺寸；这是界面测试数据，不代表当前声音。

1. 检查小、中、大三档及深浅色主题，标题、歌手、进度条和音量控件均不溢出。小号提供简洁进度；中号和大号同时显示已播放时间与总时长。
2. 启动静音测试媒体，点击组件中的暂停、播放、上一首、下一首，查看页面底部收到的操作和曲目变化。
3. 在每档进度条上拖动或用方向键调整；音量滑块在 0–100% 范围调整，静音后调整到非零音量可取消静音。三档视图同步显示操作结果。
4. 检查长标题、移除封面、禁用控制、模拟直播和音量不可用。缺失封面使用占位图；直播显示未提供进度；音量不可用时滑块及静音按钮禁用。
5. 在原生 Vela 中启用正在播放，检查封面、标题、歌手和播放状态。三档均支持播放器允许时的进度调整。音量只调整对应播放器在 Windows 混音器中的应用音量；系统总音量和其他应用不变。在系统混音器中调整该应用音量，组件同步变化。浏览器内多个标签页共用浏览器应用音量。
6. 关闭测试媒体页面，检查原生组件回到空状态或跟随系统选中的其他播放器。关闭组件后重新启用，检查订阅恢复。切换输出设备后音量仍跟随该播放器；无法准确匹配的来源禁用音量。
7. 隐藏页面后前端进度刷新暂停；再次显示或休眠唤醒后，进度从系统时间戳恢复。完全遮挡时的 Windows 可见性行为仍需按设备验证。
8. 三档均可从封面、标题和背景留白拖动窗口；播放按钮、进度和音量滑块只执行对应操作。启用“锁定位置”后，所有拖动区域均失效，播放操作仍可使用。

Windows 原生只读检查（需要在实际桌面环境运行，隔离环境可能没有媒体服务）：

```powershell
cd src-tauri
cargo test --locked native_media_api_connects_and_subscriptions_can_be_removed -- --ignored
```

打开测试页面并启动静音媒体后，可运行系统控制与事件回传验证：

```powershell
cargo test --locked native_media_controls_and_events_round_trip -- --ignored
cargo test --locked native_player_volume_round_trip_and_isolation -- --ignored
```

测试在发出任何操作前核对测试媒体的歌手与专辑，避免控制其他媒体。音量验证会恢复原音量和静音状态，并检查其他应用及系统总音量保持不变。验证完成后暂停测试音频。
