# Vela Widgets 界面设计规范

- 文档版本：v1.0
- 更新日期：2026-10-02
- 适用范围：桌面组件（日历、待办）、组件右键菜单、偏好设置窗口
- 状态：已在原型中实现，记录当前确认的视觉与交互方案；原生窗口效果（材质、圆角、尺寸切换）以 Windows 11 实机为准

本文是《产品设计文档》第 7–10 节的视觉细化。产品规则冲突时以产品设计文档为准，视觉与布局细节以本文为准。

## 1. 设计原则

1. **像系统自带的组件。** 风格以 Windows 11 Fluent 为基础，组件尺寸体系参考 macOS 桌面小组件：固定档位、每档独立排版，而不是自由缩放。
2. **材质统一，内容分级。** 所有组件共用同一种磨砂材质；尺寸越小，信息越少、字越大，不做等比例缩小。
3. **中性底色，强调色点睛。** 背景和文字使用中性黑白透明度，只有今天、选中、主要按钮和数字强调使用强调色。
4. **浅色和深色是两套独立调色，不是互相反色。**
5. **动效只用于反馈。** 120–180 ms 为主，尊重“减少动画”系统设置。

## 2. 材质

| 层 | 实现 | 说明 |
| --- | --- | --- |
| 背景模糊 | 原生 HostBackdropBrush（DirectComposition SpriteVisual），按组件圆角裁剪 | 模糊桌面壁纸，由系统合成，不依赖 CSS backdrop-filter |
| 着色层 | CSS `rgba(tint, alpha)` | `alpha = 1 − 背景透明度`，默认透明度 12%（alpha 0.88） |
| 顶部光泽 | 从上到下的白色渐变，覆盖上部 46% | 浅色强度 alpha×0.16，深色 alpha×0.035，随透明度一起变化 |
| 描边 | 1px 内描边 + 顶部 1px 内高光 | 内缩 1px，避免物理像素取整时被裁掉 |

组件窗口本身无系统阴影、无系统边框，圆角由用户在偏好设置中调节（8–30，默认 19）。右键菜单使用同一套原生磨砂，另加细颗粒噪点，圆角 11。偏好设置窗口使用 Mica（系统支持时），与标题栏共享背景。

## 3. 颜色

### 3.1 组件色板（`--wg-*`）

| Token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| tint | 247, 248, 250 | 34, 34, 36 | 着色层底色 |
| text | 黑 90% | 白 94% | 主文字、日期数字 |
| text-2 | 黑 62% | 白 68% | 次要文字、说明 |
| text-3 | 黑 44% | 白 46% | 辅助信息、星期标题 |
| text-4 | 黑 26% | 白 24% | 非本月日期、复选框边框 |
| fill / fill-hover / fill-press | 黑 4.5% / 7% / 10% | 白 6% / 9% / 5% | 按钮和格子的悬停、按下 |
| divider | 黑 7.5% | 白 8% | 分隔线 |
| stroke | 黑 10% | 白 10% | 组件和浮层描边 |
| control | 白 72% | 白 6% | 输入框、分段控件选中块 |
| accent-text | 强调色混 14% 黑 | 强调色混 38% 白 | 强调色文字，保证对比度 |
| danger | #c42b1c | #ff99a4 | 逾期、删除 |

规则：
- 浅色模式不再使用偏蓝灰的硬编码颜色；所有中性色都是黑/白透明度，叠在磨砂上自然融合。
- 强调色文字一律用 `accent-text`，不直接用原强调色，避免深色模式下发暗、浅色模式下发虚。
- 实心强调色（今天、主按钮、选中尺寸）上的文字固定白色。

### 3.2 强调色

预设 8 色：#3b67b8（默认蓝）、#805eb2、#c14289、#d4484d、#dc812e、#c39a27、#399466、#858585。在偏好设置“外观 › 强调色”中切换，组件和偏好设置即时同步。

## 4. 字体与排版

- 字体：Segoe UI Variable Text / Segoe UI / Microsoft YaHei UI；大号数字使用 Segoe UI Variable Display。
- 数字使用等宽数字（tabular-nums），日期格和计数不跳动。

| 用途 | 字号 / 字重 |
| --- | --- |
| 日历大日期（小号 / 中号） | 64 / 58，字重 300 |
| 待办计数 | 34，字重 600 |
| 大号标题（“10月”“待办”） | 16–22，字重 650 |
| 正文（任务标题、日期格） | 12.5–13 |
| 辅助信息（星期、截止日期、计数） | 10.5–12 |

## 5. 组件尺寸体系

组件不支持拖拽边缘缩放，只能在三个固定尺寸间切换。

| 档位 | 逻辑尺寸 | 拖动区域 |
| --- | --- | --- |
| 小 | 170 × 170 | 整个组件 |
| 中 | 364 × 170 | 整个组件 |
| 大 | 364 × 384 | 仅标题栏（内容区需要点选） |

- 切换入口：组件右键菜单的“尺寸 小 / 中 / 大”分段按钮，以及偏好设置中各组件页的“组件尺寸”。两处共享同一状态。
- 切换时保持窗口左上角位置，超出屏幕工作区时自动移回屏幕内，并重新应用圆角裁剪。
- 默认尺寸：日历“大”，待办“中”。旧版本保存的组件按“大”处理。
- 锁定位置后不能拖动，但仍可以切换尺寸。
- 按钮、输入框、复选框等可点击控件在拖动区域内依然可以正常点击，不会触发拖动。

## 6. 日历组件

```text
小 170×170            中 364×170
┌──────────┐          ┌───────────┬──────────────────────┐
│ 星期五    │          │ 星期五    │ 一 二 三 四 五 六 日 │
│          │          │           │          1 (2) 3  4  │
│  2       │          │  2        │  5  6  7  8  9 10 11 │
│          │          │           │ …                    │
│ 2026年10月│          │ 2026年10月 │ 26 27 28 29 30 31    │
│ 第 40 周  │          │ 第 40 周   │                      │
└──────────┘          └───────────┴──────────────────────┘

大 364×384
┌──────────────────────────────┐
│ 10月 2026          [今天] ‹ › │ ← 标题栏，可拖动
│ 一  二  三  四  五  六  日    │
│ 28  29  30   1  (2)  3   4    │
│ … 固定 6 行                   │
│──────────────────────────────│
│ 10月2日星期五          今天   │
└──────────────────────────────┘
```

- **小号**：星期（强调色文字）、超大日期、年月、ISO 周数。只显示今天，不可交互。
- **中号**：左侧同小号的今日信息，右侧迷你月历（只显示所浏览月份的日期，非本月格留空），今天用强调色实心圆。顶部显示年月、左右月份箭头；浏览其他月份时出现“今”按钮，点击回到今天。月历按月份显示 5 或 6 行，左右之间用竖向分隔线；拖动区域为左侧今日信息，右侧用于月份操作。
- **大号**：
  - 标题为强调色月份加灰色年份；“今天”胶囊按钮只在浏览其他月份或选中其他日期时出现，带淡入淡出。
  - 月历固定 6 行，切换月份时高度不跳动。
  - 日期格是 32px 圆形：悬停为浅填充；选中为强调色 16% 底加强调色文字；今天为强调色实心加白字，同时是今天和选中时按今天显示。
  - 底部显示选中日期和相对描述（今天 / 明天 / 昨天 / N 天后 / N 天前）；选中今天时相对描述使用强调色胶囊。
- 日期每分钟校准一次，跨日后自动更新。
- **节假日**：内置中国大陆 2026 年官方年度放假与调休安排。小号及中号左侧在当天有安排时以名称和休息／调休上班替代周数；中号日期旁显示小色点（放假为强调色、调休上班为警示色），悬停查看日期及名称；大号日期格右上显示“休／班”，底部显示选中日期的安排。
- **数据与设置**：分别提供显示节假日、显示调休开关，默认开启；自动更新默认关闭，开启后启动及每 24 小时检查公开项目数据的版本，仅版本变化时下载年度文件。手动检查可随时执行，显示成功检查时间、更新日期与错误提示；失败保留缓存，新年份与已有年份合并。未收录年份明确提示，不推算官方放假。年度文件发布到项目仓库后在线源生效。
- **更新说明**：设置界面说明“数据来自官方年度通知，经项目人工核对后发布”。维护者手动更新 GitHub 年度 JSON 文件并提高版本号，软件检查版本后获取新文件；更新假期数据无需升级软件，也不自动抓取政府网站。最近检查时间记录最近一次尝试，失败时显示原因，不显示成功更新提示。
- **说明入口**：节假日数据卡片的标题旁放置小号圆圈「i」按钮，数据来源及联网隐私两段说明收进提示浮层，不常驻占据卡片空间；鼠标悬停或键盘聚焦时显示，移出或失焦后关闭，Escape 可关闭。卡片保留数据年份、数据日期、最近检查／更新时间、检查按钮及检查结果。
- **卡片对齐**：节假日数据卡片沿用其他设置卡片的图标列、文字列与操作列；标题旁说明按钮与标题同一行高，最近检查／更新时间及检查结果均从文字列开始，不从图标列开始。
- **统一悬停提示**：中控及桌面组件的应用内提示统一使用 7–8px 圆角、细描边、轻阴影及明暗主题色，替换默认 `title` 文本框；中控字号 12px，桌面组件 11px。悬停约 350ms 后显示，键盘聚焦立即显示；Escape、移出、失焦或点击可关闭。浮层不接收鼠标输入，不影响点击与拖动；靠近窗口边缘时调整位置，在小号组件内限制宽高。

## 7. 待办组件

```text
小 170×170            中 364×170
┌──────────┐          ┌────────────┬────────────────────────┐
│ [✓]    5 │          │ [✓]        │ ○ 整理周报…      [今天] │
│ 待办      │          │            │ ○ 预约牙医       [9/30] │ ← 逾期红色
│ ○ 整理周报 │          │ 5          │ ○ 买咖啡豆              │
│ ○ 预约牙医 │          │ 项未完成    │ ○ 回复设计评审   [10/5] │
│ ○ 买咖啡豆 │          │ [＋ 新建]   │ 还有 1 项               │
└──────────┘          └────────────┴────────────────────────┘

大 364×384
┌──────────────────────────────┐
│ [✓] 待办                  (＋)│ ← 标题栏，可拖动
│     5 项未完成                │
│ [ 未完成 5 ][ 已完成 1 ]      │ ← 分段控件
│ ○ 整理周报并发给团队          │
│   🕒 今天                     │
│ ○ 预约牙医                    │
│   🕒 已逾期 · 9/30             │
│ … 列表分页，上／下切换                 │
└──────────────────────────────┘
```

- **图标块**：26px 圆角方块，强调色渐变底和白色对勾，是待办组件的识别标志。
- **小号**：未完成数量（大号数字）和分页显示全部未完成任务，每页最多 3 条，可直接勾选完成。
- **中号**：左侧计数、“项未完成 / 全部完成”和“新建”胶囊；右侧分页显示全部未完成任务，每页最多 4 条，带截止日期胶囊（逾期为红色）。
- 三档列表均不滚动；底部显示页码和上／下翻页按钮，第一页禁用上一页，最后一页禁用下一页。小号通过顶部标题区域拖动，中号通过左侧摘要区域拖动，列表区域留给勾选。
- **大号**：
  - 标题区：图标块、“待办”、未完成数量、圆形“＋”按钮。
  - 分段控件：浅填充轨道，选中项为白色（深色模式为浅白）浮起块加阴影，右侧显示数量。
  - 任务行：18px 圆形复选框，完成后为强调色实心加白勾，标题变灰并加删除线。截止日期带时钟图标，逾期显示“已逾期 ·”加红色文字，不只依靠颜色区分。
  - 大号按行高度分页：无截止日期每页最多 5 条，含截止日期或行内编辑时减少条数，确保内容不被裁切。编辑时暂时禁用翻页；切换筛选或尺寸回到第一页，末页任务减少时自动回到有效页。
  - 编辑、删除按钮在悬停或获得键盘焦点时出现；点击标题进入行内编辑。
  - 空状态：圆形强调色浅底对勾、提示文字，未完成页附“新建待办”按钮。
- **新建浮层**：组件内居中弹出，背后为半透明磨砂遮罩。
  - 大号：标题、关闭按钮、内容输入、截止日期、取消 / 添加。
  - 中号：隐藏关闭按钮和字段标签，日期与按钮同一行。
  - 小号：只保留内容输入和全宽“添加”按钮，Esc 取消。
- 输入框为 Fluent 样式：底边加深，获得焦点时变为强调色底线。

## 9. 偏好设置窗口

- Windows 11 设置风格：原生标题栏与窗口按钮，Mica 背景，默认 1000 × 720，最小 780 × 580。
- 左侧：搜索框和两组导航，“我的组件 / 日历 / 待办”与“外观 / 启动 / 关于”。
- 右侧：分组卡片，每张卡片包含图标、标题、说明和右侧控件。
- 组件页：在桌面显示、窗口层级（普通 / 始终置顶）、组件尺寸（小 / 中 / 大）、锁定位置；日历另有“一周的第一天”。
- 外观页：
  - 颜色模式：浅色 / 深色 / 跟随系统，每项带动态预览，见第 10 节。
  - 强调色：8 个预设色。
  - 组件圆角：8–30 滑块。
  - 背景透明度：0–100% 滑块。
- 所有设置即时生效并自动保存；失败时在窗口内提示。

## 10. 颜色模式预览动画

每个颜色模式选项内有一个抽象的小窗口预览。

- **点击切换**：选中某一模式时播放一次，约 1.5 秒：指针点击，接着出现波纹并轻按组件，然后新主题以圆形从点击处展开，太阳或月亮升起，深色模式还会闪现星星。页面加载时不播放，不会闪现错误的主题。
- **常驻循环**：
  - 浅色、深色：循环重放上述点击切换演示，周期分别为 7 秒和 7.6 秒，并错开播放，两个卡片不会同时动作。
  - 跟随系统：白天与黑夜之间平滑交替，周期 10 秒，表示主题会随系统变化。
  - 点击播放结束后，接回循环的“已切换”阶段，不从头倒放。
- 开启“减少动画”时，点击动画和循环都关闭，只显示静态预览。

## 11. 动效与可访问性

- 悬停 / 按下：120–150 ms 颜色过渡。“今天”胶囊和提示条淡入淡出约 160 ms。
- 开启“减少动画”时，组件内所有过渡关闭。
- 键盘焦点显示 2px 实线描边；图标按钮都有无障碍名称（aria-label）。
- 复选框使用 `aria-pressed`；分段控件使用 `tablist` / `tab`；尺寸选择使用 `menuitemradio`。
- 状态不只依靠颜色：逾期显示文字，今天和选中同时使用形状（实心 / 浅底）区分。

### 倒数日分页

- 小号、中号每页显示一个事件；大号每页最多显示三个事件，保留日期、重复标记及进度。
- 使用与待办一致的上／下箭头、页码及轻微纵向切换动效，不自动轮播，不滚动。
- 只有一页时隐藏分页控件；切换尺寸回到第一页，记录减少后回退到有效页。
- 小、中号内容区域可拖动，翻页按钮区域不触发拖动；大号通过标题拖动。

### 多便签与 Markdown

- 三档均保留顶部新建、删除、编辑按钮；标题从第一行非空文本自动读取并去掉格式，长标题省略但保留提示。标题区域拖动，按钮和内容可操作。
- 一个窗口保存多篇便签，每篇独立颜色和创建时间。右键菜单提供便签列表，列表显示标题、颜色和当前项，支持直接选择及键盘操作。
- 阅读时渲染 Markdown，编辑时显示原文；篇内使用 4 px 滚动条。大号编辑工具栏提供标题、加粗、列表、任务和代码快捷插入，Ctrl+Enter 完成编辑。
- 多篇时显示页码和上下按钮；编辑期间禁用切换。切换使用 340 ms 透视与纵向 3D 卡片动效，系统减少动态效果时使用短淡入淡出。
