# Vela Widgets 组件清单

版本：v0.2　日期：2026-10-03　状态：时钟、便签、倒数日已接入；待办与倒数日已加入上下分页，待 Windows 实机验收

本文列出日历、待办之后值得做的组件，以及推荐的先后顺序。视觉与尺寸遵循[界面设计规范](界面设计规范.md)，产品约束遵循[产品设计文档](产品设计文档.md)。

## 1. 筛选标准

1. **本地优先。** 默认不联网；需要网络的组件必须由用户主动启用，并说明请求内容。
2. **安静。** 不弹窗、不闪烁、不抢焦点；没有必要的信息不展示。
3. **低占用。** 隐藏或被遮挡时暂停刷新；不做常驻高频采样。
4. **三档都成立。** 小、中、大三档都要有有意义的布局；做不出小档的组件不适合桌面组件形态。
5. **一眼可读。** 主要价值在扫一眼，复杂操作仍放在中控或其他应用里。

## 3. P1：推荐优先实现

实现进度（2026-10-03）：时钟、便签、倒数日已提供三档布局、中控设置、本地保存、右键菜单和主题同步。新组件默认关闭。世界时钟当前提供 10 个常用城市，最多选择 3 个；便签以 Markdown 原文保存，支持多篇管理、自动标题、3D 切换和按创建时间自动删除；倒数日通过中控管理事件，2 月 29 日的年度纪念日在平年按 2 月 28 日计算。专注计时尚未实现。隐藏后的刷新暂停已接入页面可见性，完全遮挡时的原生行为仍需 Windows 实机验证。

### 3.1 时钟

- 用途：一个时钟组件整合时钟、闹钟、秒表、计时器，记住上次模式；世界时钟提供 10 个地区、最多选 4 个。
- 小：右下角轻量按钮切换模式；时钟显示铺满窗口的圆角方形表盘，闹钟显示最近一次提醒，秒表／计时器显示数字及必要操作。
- 中：右下角悬停胶囊切换模式；时钟显示本地及世界时间，计时器直接编辑时分秒，秒表读数、按钮和分段列表整体滚动，闹钟列表可滚动。
- 大：右下角悬停胶囊切换模式；时钟提供模拟表盘和城市，闹钟支持完整列表，秒表展示分段时长及累计时间。
- 配置：12/24 小时制、显示秒、城市列表（使用系统时区数据库，不联网）。
- 实现：时钟保持对齐刷新；切换模式和隐藏组件不停止计时。Rust 后台每秒检查到期，状态本地持久保存。秒表使用时间戳计算累计时长，计时器保存截止时间，休眠唤醒或重启后恢复／补显到期提醒。显示刷新在隐藏时暂停。
- 闹钟：最多 32 个，指定日期或每周重复；桌面和中控都可新建、编辑、启停、删除。默认仅一次且自动选择下一个有效时间。
- 秒表：开始、暂停、继续、重置、计次（最多 100 次）。
- 计时器：1 秒至 24 小时，快捷 1／5／10／25 分钟，时分秒输入，开始、暂停、继续、重置。
- 提醒：Vela 运行时到时弹出独立置顶窗口，播放系统提示音（最多 60 秒）；停止、稍后 5 分钟、全部停止，关闭提醒窗口等同全部停止。关闭组件仍提醒；退出应用后不唤醒系统，到期提醒在下次启动时补显。重复闹钟长时间错过只补显一次并计算下一次，不连续追补。
- 存储：独立 clockTools 字段，保留旧版时钟显示设置；全部工具离线运行。调整系统时间会影响基于时间戳的显示和到期时刻。
- 风险：时区名称本地化，以及夏令时切换的显示。

### 3.2 便签

- 用途：随手记录短文本，类似 Sticky Notes，但沿用 Vela 的材质。
- 三档：一个桌面窗口管理多篇便签，篇内保留细滚动条；只有点击编辑按钮才进入 Markdown 原文编辑。
- 桌面操作：顶部直接新建、删除和编辑；删除后可在 10 秒内撤销。右键提供新建、便签列表与删除当前篇。
- 标题：自动读取第一行非空内容，去掉 Markdown 格式标记；空白篇显示“新便签”。
- 切换：底部上下箭头与页码，轻微透视、倾斜、缩放及前后层次的 3D 卡片动效；编辑时禁用切换，减少动态效果设置下使用淡入淡出。
- 渲染：标题、强调、删除线、引用、分隔线、嵌套列表、任务列表、表格、链接、图片、代码高亮、脚注、KaTeX 公式及 Mermaid 图表。原始 HTML 按文本显示；图片仅在点击“加载图片”后请求，支持网络及内嵌图片。
- 配置：每篇独立强调色（7 色预设和自定义调色盘），自动删除采用全局默认时长＋单篇覆盖：永不删除、创建后 1／7／30 天或自定义小时；新便签默认跟随全局，单篇可选择跟随默认或独立设置（含永不删除），已有独立限时设置保留。显示创建时间及预计删除时间，全局初始为永不删除。删除规则收进标题「i」悬停／键盘聚焦提示；缩短时长导致立即到期时，保存前显示受影响数量并确认。
- 实现：450 ms 防抖自动保存到 SQLite，关闭前等待保存；旧单篇内容自动迁移，创建时间在迁移时记录。Markdown 和图表按需加载，到期内容在运行中或下次启动时清理。
- 边界：仍是单窗口，无多窗口实例；最多 200 篇，每篇 20000 字。相对图片路径和本地图片附件尚未接入。

### 3.3 倒数日

- 用途：考试、纪念日、假期倒计时，或“已经过去 N 天”。
- 小：每页一个事件，大号天数加事件名。
- 中：每页一个事件，显示名称、天数和日期。
- 大：每页最多三个事件，按剩余天数排序，带进度条。
- 翻页：手动上／下翻页，沿用待办的箭头、页码与纵向动效；只有一页时隐藏控件，不滚动、不自动轮播。
- 配置：事件名、日期、按年重复、正数或倒数。
- 实现：每天零点刷新一次，成本极低。
- 风险：几乎没有。农历纪念日要等日历的农历能力完成后再做。

### 3.4 专注计时

- 用途：番茄钟或自定义倒计时。
- 小：环形进度加剩余时间；点击开始或暂停。
- 中：计时环加当前专注的待办标题，以及今日完成次数。
- 大：计时器、今日专注记录和待办选择列表。
- 配置：专注时长、休息时长、结束提示（系统通知或静默）。
- 实现：计时由 Rust 端以时间戳为准，前端只负责显示，避免 WebView 节流造成误差。
- 联动：可以从待办选择任务，属于跨组件联动，需要显式启用，规则与“日历联动”一致。
- 风险：结束提示是 Vela 唯一会主动打扰用户的地方，默认使用静默模式加组件内高亮。

## 4. P2：值得做，有前置条件

### 4.1 正在播放

- 用途：显示当前媒体，并提供播放/暂停、上一首、下一首控制。
- 小：封面加播放按钮。中：封面、标题、歌手和控制按钮。大：再加进度条。
- 实现：通过 Windows 的 GlobalSystemMediaTransportControls（SMTC）读取，由 Rust 端订阅事件，不轮询。
- 风险：部分播放器不接入 SMTC；没有媒体时需要设计空状态。

### 4.2 天气

- 用途：当前天气和未来几天的预报。
- 小：图标、温度和城市。中：再加未来 5 天。大：再加逐小时曲线。
- 前置条件：默认不启用网络。用户在中控里主动开启后才联网，并说明会请求哪个服务、多久请求一次。
- 实现：推荐 Open-Meteo（无需密钥）；30～60 分钟刷新一次，失败时显示上次数据和更新时间；城市手动选择，不做定位。
- 风险：与产品文档“默认无网络请求、天气轮询”的约束冲突，需要先修订该约束。

### 4.3 系统状态

- 用途：查看 CPU、内存、磁盘和电池。
- 小：单个指标的环形图。中：2～4 个指标条。大：带近 5 分钟的趋势。
- 实现：Rust 端采样，可见时 2～5 秒一次，被遮挡或最小化时停止采样。
- 风险：与“不做常驻系统监视”的约束冲突，需要用户启用，并在关于页说明资源开销。

### 4.4 习惯打卡

- 用途：每日习惯记录。
- 小：今日完成数。中：习惯列表加本周 7 天格子。大：月度热力图。
- 实现：数据模型类似待办，可以复用列表和勾选的视觉。
- 风险：与待办的“重复任务”边界需要先定清楚，避免两个组件做同一件事。

## 5. P3：暂缓

- 相框：轮播本地文件夹里的图片。只在可见时解码，并限制图片尺寸，避免占用内存。
- 快捷启动：固定几个应用或文件夹的图标。与开始菜单、任务栏重叠，等用户反馈后再决定。

## 6. 不推荐

| 组件 | 原因 |
| --- | --- |
| 股票、汇率、新闻 | 需要联网，信息更新频繁且嘈杂，违背“安静”原则 |
| 剪贴板历史 | 有隐私风险，而且系统已有 Win+V |
| 邮件、第三方日历 | 需要账号和授权，属于第一版明确不做的范围 |
| 网页嵌入 | 安全边界与资源占用都不可控 |

## 7. 新组件接入要求

每个新组件都要满足以下要求：

1. 在编译期组件注册表中声明类型标识、名称、默认尺寸档位、可用档位和默认配置。
2. 提供小、中、大三档布局。某一档确实无法成立时，在注册表中去掉该档，并在右键菜单中隐藏它。
3. 只使用 `--wg-*` 色彩令牌，浅色和深色都要验收。
4. 右键菜单沿用通用项（偏好设置、置顶、尺寸、关闭），组件专属项放在最上方，例如待办的“新建待办”。
5. 隐藏或被遮挡时暂停定时刷新。
6. 在中控“组件”导航下增加对应页面，配置项即时生效并自动保存。

### 组件编辑与时间工具交互优化（2026-10-03）
- 便签保留 Markdown 原文编辑与自动保存，编辑区域使用透明纸面和原生字体，不再出现输入框底色；格式工具移到底部轻量工具栏，所有尺寸可用，只在保存失败时提示。
- 新建待办以列表中的输入行展开，输入名称、可选日期，回车或加号提交；提交后支持继续添加，Esc 或关闭按钮收起。小、中、大尺寸均支持，分页为新增行保留空间，不覆盖原列表。
- 待办与闹钟共用紧凑日期字段（YYYY/MM/DD）和锚定日历浮层，无遮罩。小窗口采用紧凑月历，浮层限制在组件范围内，保留原有控件材质、键盘操作、清除及月份切换。
- 时钟三种尺寸共用精细指针表盘，60 个刻度、完整数字和红色秒针；指针每秒更新，数字时间的秒数仍由设置控制。隐藏时暂停前端刷新。
- 桌面秒表的读数、操作按钮和计次记录整体滚动，不再把记录限制在狭小的独立滚动区。设置页秒表和计时器采用紧凑横向布局，计次记录最多显示 200px 后滚动。
- 偏好设置的时钟工具默认不选择，点击工具展开、再次点击收起，浏览选择仍与桌面模式独立。开启开关的强调色在深浅模式下均填满轨道；强调色前景按颜色亮度选择，保持可读性。

### 日期导航与小号时钟沉浸布局（2026-10-03）
- 日期选择参考 Windows 系统日历：左上方合并显示“2026年08月”及下拉箭头，右侧上下箭头翻月，星期与日期网格居中对齐，选中日期使用浅灰底、深色文字和细描边的方格，底部左侧清除、右侧今天，保留组件材质。点击年月显示 12 个月，再点击年份进入年份列表，可按组翻页。选择年份后进入月份，选择月份后返回日历，最后选择日期才保存。年、月选择尊重最早／最晚日期，支持键盘方向键操作，小尺寸内不溢出。
- 小号时钟模式使用铺满 170×170 窗口的圆角方形表盘，保留红色秒针，不占用标题和日期栏空间。右下角轻量模式按钮仅在鼠标靠近底部预留区域或键盘聚焦时显示，菜单展开期间保持可见；点击菜单外或切换到其他窗口时关闭，小号时钟、闹钟、秒表和计时器统一使用该入口，菜单标记当前模式；其他工具模式同样隐藏常驻模式栏，为浮层预留安全间距，列表不与按钮重叠。右键仍可切换时钟、闹钟、秒表、计时器，切换不影响运行中的工具。
- 小号其他工具保留内容布局并共用右下角入口，中、大尺寸保留现有布局；沉浸表盘空白区域可拖动，遵守锁定位置设置。表盘与按钮适配深浅色，动画尊重减少动态效果设置。

### 日历日程与列表（2026-10-03）

- 日历保留原来的日期／月历样式，新增“日程”和“列表”。偏好设置中的日历样式明确控制桌面展示，右键菜单也可切换；打开设置或编辑日程不会自行切换桌面样式。
- 共用本地日程数据：支持名称、开始／结束日期、全天或具体时间段、地点、颜色；支持新建、编辑、删除确认。设置中统一管理，桌面日程和列表可直接新建及点击事件编辑。月历标记有日程的日期，双击日期可新建或编辑当日首条日程。
- 日程：小尺寸显示当天近期事项，中尺寸并列显示今天和明天，大尺寸为双列时间轴；全天事项放在上方，重叠定时事项并排，当前时刻用红线标记。保留左右日期翻页；大尺寸每天的时间轴独立支持滚轮浏览完整 0–24 时，不再使用上下时段按钮。底部回到今天使用图标并提供悬停说明，点击恢复当天及当前时段。小、中尺寸每天的日程区独立支持滚轮查看全部事项，不再固定截取两项。
- 列表：按日期分组，显示农历、节假日及调休、事项名称和时段；连续假期显示起止日期。小、中、大均按可用空间分页，不丢弃超出当前页的事项。今天已结束的定时日程不再列入近期列表，全天与正在跨日的事项保留。
- 与既有节假日显示开关共用，联网假期文件只负责假期数据，本地个人日程不上传。当前为本地一次性日程；不包含云日历同步、重复日程或到时通知。旧版本设置默认继续展示日期／月历。

- 沉浸式底部控件：日程／列表翻页和便签字数、翻页仅在鼠标靠近底部或键盘聚焦时显示；触屏设备常显。便签小、中尺寸缩紧标题和内边距，底部控件浮层不再单独占行，正文末尾保留安全空间；保存失败与删除撤销提示及时显示。日程／列表同样取消独立翻页占行，使用紧凑的居中浮层；便签与日程浮层均有随主题变化的不透明底色、细描边与轻阴影，隔开下方文字，内容末尾留出安全空间以便滚动查看。

- 底部浮层采用胶囊形：便签左侧独立圆形字数徽标，右侧页码与翻页共用胶囊；日程翻页共用居中胶囊。大号日程时间轴延伸至下边缘，不再为隐藏按钮常驻留白，滚动末尾保留安全空间；浮层底色隔开背后文字，靠近底部或键盘聚焦时显示。
